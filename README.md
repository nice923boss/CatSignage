# CatSignage 電子看板

Windows 用的輕量電子看板程式。同一個程式裝在兩種電腦上：辦公室電腦當「發送端」管理圖片與影片，門市電腦當「接收端」自動同步素材並全螢幕輪播。兩台電腦透過 [Tailscale](https://tailscale.com/) 直接連線，不需要雲端伺服器，也沒有帳號系統。

## 功能

- **發送端**：加入圖片（jpg、jpeg、png、gif、webp）與影片（mp4、webm），調整播放順序與每張圖的秒數，列表附縮圖；每一列有「原檔位置」按鈕，可以在檔案總管找到原始檔自行刪除。同一檔案重複加入只存一份。
- **接收端**：每分鐘檢查一次清單版本，有變動才下載；下載中斷會用 HTTP Range 接續已下載的部分，一個檔案最多連試 5 次，雜湊比對通過才會被播出。
- **全螢幕輪播**：新素材下載完自動接進輪播，不中斷畫面；按 Esc 退出播放。
- **開機自動播放**：接收端可設定登入 Windows 後自動開啟並進入播放。
- **素材回收**：已離開清單的舊素材依保留期限（預設 30 天）、快取容量上限、磁碟保留空間（預設 500 MB）自動清理；清單內的檔案永遠不刪。
- **Tailscale 檢查**：啟動時若找不到 Tailscale 位址，會說明是「沒安裝」還是「沒連線」，並可開啟隨程式附上的離線安裝指引。

現場人員的操作方式見 [docs/現場操作說明.md](docs/現場操作說明.md)。

## 運作方式

```
發送端（辦公室）                              接收端（門市）
  媒體庫 + SQLite                               SQLite + 本機素材快取
  HTTP 供檔服務  ── Tailscale 100.x.x.x ──>   每 60 秒 GET /api/health
    /api/health     （回傳清單版本）            版本有變才 GET /api/playlist
    /api/playlist   （播放清單）                缺的檔案 GET /api/file/<sha256>
    /api/file/<sha256>（支援 Range）            下載完驗證 sha256，再交給播放視窗
```

- 供檔服務只綁在本機的 Tailscale 位址（100.64.0.0/10），預設埠 28480，不會開在區網或公網介面上。
- 素材以 sha256 定址，清單版本是清單內容的雜湊，兩邊版本一致就不重抓。
- 資料放在 `%APPDATA%\CatSignage\<profile>`，預設 profile 名稱是 `default`。

## 系統需求

- Windows 10 或 11（x64）
- 發送端與接收端都安裝 Tailscale，並登入同一個 tailnet

## 從原始碼執行

需要 Node.js 22.12 以上（`@electron/rebuild` 的要求），開發與打包在 Node.js 24 上驗證過。

```bash
npm install
npm start
```

或直接執行 `scripts\start.bat`（缺套件時會自動安裝）。結束所有執行中的實例用 `scripts\stop.bat`。

同一台電腦要同時跑發送端與接收端，用不同的 profile 分開資料：

```bash
npx electron . --profile=tx
npx electron . --profile=rx
```

## 打包

```bash
npm run pack
```

產出在 `release\`：

- `CatSignage-Setup-<版本>.exe`：NSIS 安裝檔，可選「僅為我安裝」，不需要系統管理員權限。
- `CatSignage-Portable-<版本>.exe`：免安裝版。

反安裝會移除程式、捷徑與指向這份安裝的開機自動啟動項目，最後詢問是否一併刪除 `%APPDATA%\CatSignage`（預設「否」）；靜默反安裝與升級安裝一律保留資料。

## 專案結構

```
src/main/            主行程
  sender/            媒體庫、縮圖、HTTP 供檔服務
  receiver/          同步、續傳下載、素材回收
  player/            全螢幕播放視窗與 catmedia:// 協定
  db/                SQLite 資料表（better-sqlite3）
  lib/               雜湊、Tailscale 位址偵測、安裝指引
src/preload/         renderer 與主行程之間的 IPC 介面
src/renderer/        主視窗、播放視窗、縮圖產生頁
build/               圖示與 NSIS 反安裝自訂腳本
docs/                現場操作說明、Tailscale 安裝指引
scripts/             啟動、停止與圖示產生腳本
```

## 已知限制

- **沒有程式碼簽章**：安裝檔與執行檔未簽章，經網路傳遞的檔案第一次執行會跳「Windows 已保護您的電腦」，要點「其他資訊」再按「仍要執行」。
- **沒有帳號與加密層**：安全性完全建立在 Tailscale 網路本身，tailnet 內任何裝置都能讀取清單與素材。請用 Tailscale ACL 控制誰能連到發送端，不要把埠號用其他方式對外開放。
- **只支援 Windows x64**，播放只輸出到主螢幕，沒有時段排程。
- **跨機器的斷線續傳只在同一台電腦上以故障注入驗證過**（主動切斷連線、重試退避、跨次同步從 `.part` 續傳），沒有在真實不穩的網路上測過。
- **多台接收端同時下載只驗證了正確性**：同一台電腦起 6 個接收端同時下載 16 個素材，逐檔雜湊全部相符，發送端記憶體增幅約 12 MB；沒有量測真實網路下的頻寬與延遲。
- **長時間播放**：視窗模式連續輪播 30 分鐘記憶體平穩，全螢幕模式沒有做過 30 分鐘以上的連續測試，連播數天的行為也未知。
- **按下「開始播放」不一定從清單第 1 項開始**：播放視窗在下載期間就已預先建立並輪播已就緒的素材，換來的是按下播放不會先黑一段畫面；繞完一圈後順序即與清單一致。
- **曾發生一次播放視窗自行關閉，之後無法重現**，成因未定位。
- **開發用環境變數 `CATSIGNAGE_FAKE_TAILSCALE`**：可模擬「沒安裝」或「沒連線」以檢查啟動提示，只影響那個提示視窗的判定，正常執行不會設定。
- 啟動項寫在 `HKCU`，同一台電腦有多個 Windows 帳號時，每個帳號要各自安裝與設定。
