安裝 Tailscale，CatSignage 才連得起來

這台電腦上找不到 Tailscale 的連線位址，所以辦公室與門市之間還無法互相傳素材。照下面的步驟做完就好，全程大約五分鐘。

一、為什麼需要 Tailscale

CatSignage 沒有雲端伺服器，也沒有帳號密碼。辦公室電腦與門市電腦是直接連線傳檔，而這條線路由 Tailscale 建立。兩台電腦都裝好 Tailscale 並登入同一個帳號，才會彼此看得見。

沒有裝 Tailscale 時，CatSignage 仍然可以開啟與設定，門市電腦也會繼續播放已經下載的素材，但是無法取得新素材。

二、安裝步驟

  1. 用瀏覽器打開 https://tailscale.com/download/windows，按「Download Tailscale for Windows」。
  2. 執行下載回來的安裝檔，一路按下一步完成安裝。過程中不需要改任何設定。
  3. 安裝完成後，Windows 右下角工作列會出現 Tailscale 圖示，並自動跳出登入畫面。
  4. 選擇登入方式（Google、Microsoft、GitHub 等皆可），兩台電腦務必登入同一個帳號。
  5. 登入完成後，瀏覽器會顯示連線成功，工作列圖示會從灰色變成正常狀態。
兩台電腦要用同一個帳號。辦公室電腦登入 A 帳號、門市電腦登入 B 帳號的話，兩台會在不同的網路裡，永遠看不到對方。

三、確認裝好了

按下鍵盤 Win + R，輸入 cmd 按確定，在黑色視窗貼上這一行後按 Enter：

tailscale ip -4

畫面回一個 100. 開頭的位址（例如 100.101.102.103）就代表成功了。

看到什麼代表怎麼處理
100 開頭的位址正常回到 CatSignage，關掉程式再打開一次
找不到 tailscale 命令還沒安裝回到第二節重新安裝
提示尚未登入裝好但沒登入點工作列的 Tailscale 圖示，選 Log in

四、回到 CatSignage

  1. 把 CatSignage 關掉，重新開啟。
  2. 辦公室電腦（發送端）在「媒體庫」看「供檔服務」那一列，顯示「供檔中 http://100.x.x.x:28480」就成功了。把這串位址記下來。
  3. 門市電腦（接收端）在「設定」頁把那串位址填進「發送端 IP」，埠號填 28480。

五、還是連不起來

現象檢查處理方式
裝好了但還是沒有 100 位址工作列圖示是否顯示已連線點圖示選 Connect，或登出後重新登入
兩台都有位址但連不到是否登入同一個帳號在 Tailscale 管理頁 確認兩台都列在同一份清單裡
公司網路裝不起來是否有防火牆或群組原則限制請資訊人員協助放行 Tailscale
門市電腦畫面停在舊素材辦公室電腦是否開著辦公室電腦開機並打開 CatSignage，門市會自己補下載
Tailscale 個人方案免費，一般門市使用量不需要付費。安裝後它會常駐在背景，開機自動連線，平時不需要再操作。
