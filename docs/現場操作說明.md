# CatSignage 電子看板操作說明

給門市現場人員與辦公室管理人員看的操作手冊。照著做即可，不需要任何技術背景。

---

## 一、這套系統怎麼運作

同一個程式安裝在兩種電腦上，第一次打開時選擇這台是哪一種：

| 角色 | 裝在哪 | 做什麼 |
|------|--------|--------|
| 發送端 | 辦公室電腦 | 放圖片與影片，排播放順序 |
| 接收端 | 門市播放電腦 | 自動把素材抓下來，全螢幕輪播 |

兩台電腦透過 Tailscale 直接連線，中間沒有經過任何伺服器，也沒有帳號密碼。前提是兩台都已安裝 Tailscale 並登入同一個網路。

門市電腦每分鐘會自動去問辦公室電腦一次：清單有沒有變。沒變就什麼都不做，有變才下載新素材。所以辦公室換了圖，門市不用叫人去按任何按鈕，最慢一分鐘後就會開始更新。

---

## 二、安裝

1. 拿到 `CatSignage-Setup-0.2.0.exe`，在電腦上雙擊執行。
2. 第一頁「安裝選項」選「僅為我安裝」，按「下一步」。選「所有使用者」會跳出要求系統管理員權限的視窗。
3. 第二頁「選取安裝位置」用預設的就好，按「安裝」。這一步要跑一到兩分鐘，需要約 390 MB 硬碟空間。
4. 第三頁「即將完成安裝」按「完成」，程式會自己打開。
5. 桌面與開始功能表會出現「CatSignage 電子看板」捷徑。

安裝過程不需要系統管理員權限，也不會動到 Windows 的其他設定。

### 如果跳出「Windows 已保護您的電腦」

這個程式沒有購買微軟的程式碼簽章憑證，檔案若是透過網路傳送（雲端硬碟、郵件），
第一次執行時 Windows 會跳藍色警告視窗。點左下角「其他資訊」，再按「仍要執行」即可。
用隨身碟拷貝過去的檔案通常不會跳這個視窗。

### 不想安裝的話

直接執行 `CatSignage-Portable-0.2.0.exe`，功能一樣，但每次開啟會慢幾秒。

### 要移除的時候

在 Windows 設定的「應用程式」找到 CatSignage 移除，或執行安裝目錄裡的「Uninstall CatSignage.exe」。
移除會清掉程式本體、兩個捷徑與開機自動啟動項目。最後會問「要一併刪除這台電腦上的 CatSignage 素材與設定嗎？」：

- 選「否」（預設）：保留素材與設定，重裝後可以直接接續使用。
- 選「是」：永久刪除「設定」頁「開啟資料夾」打開的那個目錄，無法復原。

升級安裝新版時不會問，素材與設定一律保留。

### 如果跳出「CatSignage 需要 Tailscale」

每次開啟程式時，CatSignage 會先看這台電腦有沒有 Tailscale 的連線位址（100 開頭那一組）。
找不到就會跳一個提示視窗，有兩種寫法：

| 視窗上的第一行 | 代表什麼 | 怎麼處理 |
|---|---|---|
| 這台電腦還沒有安裝 Tailscale | 電腦裡找不到 Tailscale 程式 | 按「開啟安裝說明」，照著網頁一步一步裝完再重開 CatSignage |
| Tailscale 已安裝，但目前沒有連線位址 | 裝了，但還沒登入或目前是中斷狀態 | 點工作列的 Tailscale 圖示登入或連線，再重開 CatSignage |

按「開啟安裝說明」會用瀏覽器打開一份圖文說明（`Tailscale-安裝指引.html`），這份說明隨程式一起安裝在電腦裡，沒有網路也打得開。
按「稍後再說」可以直接關掉提示繼續操作，門市電腦已經下載好的素材照樣會播，只是抓不到新素材。

## 三、辦公室電腦（發送端）第一次設定

1. 打開 CatSignage。
2. 在「設定」頁，執行模式選「發送端」。
3. 左邊會出現「媒體庫」，點進去。
4. 看「供檔服務」這一列，顯示「供檔中 http://100.x.x.x:28480」就代表正常運作了。**把這串位址記下來，門市電腦要填。**

如果顯示的不是「供檔中」，代表 Tailscale 沒開或沒登入。先把 Tailscale 打開再回來按「重新啟動服務」。

### 加入素材

1. 在「媒體庫」按「加入素材」。
2. 選圖片（jpg、jpeg、png、gif、webp）或影片（mp4、webm），可以一次選多個。
3. 加進來後，播放清單會照加入順序排列，「預覽」欄顯示縮圖，影片取開頭附近的畫面。

每一列可以做的事：

- **上移、下移**：調整播放順序。
- **秒數**：圖片停留幾秒，預設 8 秒，可以逐張改。影片不用設，播完自動換下一個。
- **原檔位置**：打開檔案總管並選取當初加入的那個原始檔。
- **移除**：從清單移除。門市電腦下次同步時會跟著移除。

加入時程式會複製一份到自己的資料夾，之後播放與傳送都用這份。原始檔可以用「原檔位置」找到後自行刪除或搬走，不影響播放。
原始檔已經搬走或刪掉時，按「原檔位置」會顯示「原始檔已不在原位置」。

同一張圖重複加入不會佔兩份空間，系統會自動辨識並略過。

## 四、門市電腦（接收端）第一次設定

1. 打開 CatSignage。
2. 在「設定」頁，執行模式選「接收端」。
3. 「發送端 IP」填辦公室電腦那串 `100.` 開頭的位址。
4. 「發送端埠號」填 28480（如果辦公室那邊沒改過就是這個）。
5. 「素材保留期限」保持 30 天，「快取容量上限」保持 0（不限制），「磁碟保留空間」保持 500 MB 即可。硬碟較小的門市電腦可以把快取容量上限設成例如 5 GB。
6. **勾選「開機自動播放」**。這樣門市電腦每天早上開機後，會自己打開程式並直接進入全螢幕播放，不需要人去點。

設定完成後，左邊點「播放」，可以看到：

- 「發送端連線」按「測試連線」，正常會顯示連線成功。
- 「同步」區塊會自動開始下載，「本機素材」列出每個檔案的狀態，全部變成「就緒」代表下載完了。
- 按「開始播放」進入全螢幕輪播。

## 五、日常操作

### 辦公室要換素材

1. 在「媒體庫」加入新素材、移除舊素材、調整順序。
2. 做完就好，不用通知門市，也不用去門市按任何東西。
3. 門市電腦最慢一分鐘會發現清單變了，自動下載新檔案。
4. 新檔案下載完會自動接進正在播放的輪播，不會中斷畫面。

### 門市電腦日常

- 早上開機：程式自己啟動、自己進全螢幕播放，人不用動。
- 要退出播放：按鍵盤左上角的 **Esc**，回到設定畫面。
- 要重新播放：左邊點「播放」，按「開始播放」。
- 要關機：先按 Esc 退出播放，再正常關機。

### 舊素材會自己清掉

已經從播放清單移除、而且超過 30 天沒有再播到的檔案，門市電腦會自動刪除，硬碟不會愈積愈滿。還在清單裡的檔案永遠不會被刪。

另外兩個情況也會提早回收已離開清單的舊素材，從最久沒播的開始刪：

- 設了「快取容量上限」，素材總量超過上限時。
- 下載新素材前發現硬碟剩餘空間扣掉「磁碟保留空間」後放不下時。回收完仍放不下，就跳過那個檔案，「同步」區塊會顯示需要多少、剩多少。

「播放」頁的「素材回收」列會顯示最近一次回收的時間、個數、釋出的空間，以及目前快取大小。

## 六、遇到狀況怎麼辦

| 現象 | 先檢查 | 處理方式 |
|------|--------|---------|
| 門市畫面沒有更新 | 辦公室電腦是不是關機了 | 辦公室電腦開機並打開 CatSignage 即可，門市會自己補下載 |
| 「測試連線」失敗 | 兩台電腦的 Tailscale 是否都在連線狀態 | 打開 Tailscale 確認都是已連線，再按一次「測試連線」 |
| 素材一直卡在「下載中」或顯示下載失敗 | 網路是否不穩 | 斷線時程式會自己接著已下載的部分續傳，一個檔案最多連試 5 次；仍失敗就等下一分鐘的自動同步再接著傳，也可以按「立即同步」馬上重試。檔案沒下載完不會被播出來，畫面不會有半張圖 |
| 同步狀態顯示「磁碟空間不足」 | 門市電腦硬碟還剩多少 | 清出硬碟空間，或調低「磁碟保留空間」後按「立即同步」 |
| 清單看起來不對 | 版本號兩邊是否一致 | 按「強制重新取得清單」，會重新抓一份完整清單 |
| 播放畫面黑掉 | 是不是所有素材都被移除了 | 辦公室加回素材即可 |
| 供檔服務顯示「未啟動」 | Tailscale 是否開著 | 打開 Tailscale 後按「重新啟動服務」 |
| 開程式就跳「CatSignage 需要 Tailscale」 | 這台電腦有沒有裝好並登入 Tailscale | 按「開啟安裝說明」照著做，細節見第二節同名段落 |

### 需要看檔案放在哪

在「設定」頁最下方「系統資訊」按「開啟資料夾」，會打開這台電腦存放素材與設定的位置。一般情況不需要動裡面的東西。

---

## 七、注意事項

- 兩台電腦都要保持 Tailscale 登入，這是唯一的連線方式。
- 這套系統沒有帳號密碼，安全性建立在 Tailscale 網路本身。不要把服務埠號透過其他方式對外開放。
- 門市電腦播放期間請勿關閉程式，關掉就沒有畫面。
- 影片檔請控制在合理大小，門市電腦第一次下載大檔案需要時間。
- 目前一台門市電腦只輸出到主螢幕，不支援指定第二螢幕。
- 目前沒有時段排程功能，程式開著就是一直輪播。
